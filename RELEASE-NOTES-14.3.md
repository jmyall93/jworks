# JWorks v14.3 — Responsive Workspace

Built from v14.2 with no new database migrations.

- Responsive project hero and mobile-sized project metrics.
- Back-to-projects breadcrumb, primary Task / Reports / Schedule / Edit actions, compact overflow for administrative actions.
- Edit project and Project settings use one existing modal.
- Schedule links to the existing plan view; existing Gantt/critical path tools remain available there.
- Four-item mobile bottom navigation; existing More sheet retained.
- Single-column mobile forms, full-height mobile dialogs, touch-sized controls and reduced page overflow.
- Existing field report attachment API and data are unchanged.

## Test before production

Test mobile widths 320, 375, 430 and 768 pixels, desktop, project menu, schedule, field report upload/download, dashboard, calendar and company portal. Back up the database before deployment. No live deployment testing was performed.
