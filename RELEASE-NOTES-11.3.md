# JWorks 11.3

## Highlights
- Renames Inbox to **Quick Notes** with clearer capture → convert/dismiss workflow.
- Moves **Company Portal** and **JWorks Owner** into the System navigation group.
- Adds **Import Center** with separate Project and Task Excel templates, server-side XLSX preview/validation, project-code matching, and confirmation before import.
- Upgrades Roadmap into a portfolio intelligence view with health, progress, milestones, budget and attention indicators.
- Mobile navigation now respects phone safe areas, uses five aligned destinations, and gives Quick Notes a first-class mobile capture destination.
- Preserves V11.2.8 SOW document controls and the working two-worker AI architecture.
- Includes starter Excel templates directly in the deployed app.

## Storage note
SOW attachment/package metadata remains a foundation item. Persistent contractor PDF/file storage is intentionally not faked in D1; it requires R2 or another object store before file upload is enabled.
