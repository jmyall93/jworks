# JWorks 13.0.0 — Focused Intelligence UX

- Replaces the dashboard with a restrained Command Center built around Portfolio Health, the top four attention items, Portfolio Pulse, My Day, and Since You Were Here.
- Removes the prominent AI dashboard block and treats intelligence as an embedded JWorks capability.
- Renames user-facing AI language toward outcomes: Ask JWorks, SOW Studio, Create Actions, Project Builder.
- Simplifies project navigation to Overview, Plan, Work, Financials, Documents + More while retaining advanced tools.
- Adds a project Overview focused on attention, next work, and a concise snapshot.
- Simplifies task creation to task, owner, due date, priority, and project; advanced fields remain behind + Details.
- Preserves existing APIs, D1 schema, demo workspace, migration history, and Cloudflare deployment configuration.
