# JWorks 12.2.0 — Project Lab + Demo Workspace

## Project Lab
- Expands the public Free Tools area into JWorks Project Lab.
- Categories: Build, Calculate, Analyze, Assess and AI.
- Adds Project Rescue, schedule/SOW/RAID/migration analyzers and practical calculators.
- Tools remain usable without creating an account and route naturally into the JWorks trial.

## Demo Workspace
- Adds a fictional Northstar Industries portfolio with eight connected projects.
- Includes tasks, dependencies, milestones, risks/issues, approval, procurement, meeting and decision examples.
- Adds Load, Reset and Clear Demo Data controls.
- Demo data is tracked in a dedicated demo_records ledger; Clear targets only ledger-registered records.
- Adds Presentation Mode with a recommended customer-demo story.

## Database
- Migration 0010 adds the demo-record ledger. Existing migrations and customer data are preserved.
