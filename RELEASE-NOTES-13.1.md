# JWorks 13.1 — Simplification & Reliability

## Simpler daily experience
- Main navigation reduced to Home, Projects, My Work, Reports and Ask JWorks, with secondary tools under More.
- Projects grouped by Active, Upcoming, On Hold and Completed; non-active work no longer competes in normal My Work/dashboard attention.
- Tasks grouped into To Do, Doing and Done, with completed work collapsed by default.
- Project/task forms use progressive disclosure for secondary fields.

## Project planning repaired
- Cloud CRUD for project phases is now implemented.
- Task phase/assignee/hour/tag fields are persisted in D1 via migration 0011.
- Plan workspace combines phases, an all-task project Gantt, milestones and a dependency-based critical path view.
- Project Gantt can be printed/saved as PDF using a dedicated landscape print view.

## Reporting simplified
- Full Report Builder removed from the project workspace and promoted to a top-level Reports workspace.
- Project Status remains a quick report workflow.
- Custom report templates can be saved and report schedule definitions can be managed from Reports.

## Lifecycle
- Projects support Upcoming, Active, On Hold and Completed states.
- Upcoming/On Hold project tasks are suppressed from normal active-work attention until the project is active.
